직관적인
디자인을 추구합니다.

정보의 우선순위를 명확히 하고 익숙한 위치에 기능을 배치해, 별도의 설명 없이도 어디에 무엇이 있는지 알 수 있는 화면을 만듭니다.

읽기 편한 글자와 누르기 쉬운 버튼, 다양한 화면에 맞는 레이아웃으로 사용자가 편안하게 목적을 달성할 수 있도록 디자인합니다.

디자인부터 퍼블리싱까지

웹 페이지 컨텐츠 제작과 UI/UX 디자인, 구현의 전반적인 과정을 다양한 도구를 활용하여 수행할 수 있습니다.

  • HTML5

    시맨틱 태그를 활용해 페이지의 영역과 정보의 위계를 구성할 수 있습니다. 링크, 목록, 입력 폼 등을 마크업하고, 이미지 대체 텍스트와 폼 레이블을 작성해 기본적인 웹 접근성을 고려합니다.

  • CSS3

    Flex와 Grid를 활용해 레이아웃을 구성하고, 미디어 쿼리로 PC·태블릿·모바일에 대응하는 반응형 페이지를 제작할 수 있습니다. 가상 요소와 transition, animation을 활용해 버튼 효과와 기본적인 모션을 구현합니다.

  • JavaScript

    DOM과 이벤트를 활용해 요소의 내용, 스타일, 속성을 변경할 수 있습니다. 탭, 아코디언, 팝업, 모바일 메뉴를 구현하고, Swiper를 활용해 슬라이드와 페이지네이션을 구성할 수 있습니다.

  • Figma

    와이어프레임부터 상세 시안까지 제작할 수 있습니다. Auto Layout과 컴포넌트, Variant를 활용해 반복되는 UI를 관리하고, 프로토타입으로 화면 이동과 인터랙션을 표현합니다. 퍼블리싱에 필요한 간격, 크기, 색상 확인과 이미지·아이콘 추출도 가능합니다.

  • Photoshop

    이미지의 배경 제거, 색상 보정, 합성, 리터칭을 할 수 있습니다. 레이어와 마스크를 활용해 팝업, 배너, 포스터, 상세페이지를 제작하고, 사용 환경에 맞춰 이미지 크기와 저장 형식을 조정합니다.

  • Illustrator

    펜 도구와 패스파인더를 활용해 로고, 아이콘, 간단한 일러스트를 제작하고 수정할 수 있습니다. 도형과 타이포그래피를 조합해 그래픽을 구성하고, 웹에서 사용할 수 있도록 SVG 등의 형식으로 내보냅니다.

  • Git / Github

    커밋으로 변경 내용을 기록하고, 브랜치를 나누어 작업할 수 있습니다. 원격 저장소에 코드를 올리거나 내려받고, Pull Request를 통해 변경 사항을 공유하며 팀 프로젝트에 참여할 수 있습니다.

  • ChatGPT

    디자인 콘셉트에 맞는 이미지를 생성하고, 배경 제거와 이미지 수정으로 작업에 필요한 시각 자료를 제작할 수 있습니다. HTML·CSS·JavaScript 코드의 초안 작성과 오류 원인 파악에 활용하며, 제안된 코드를 이해하고 실제 동작을 확인해 작업에 적용합니다.
